# Contract Breaker — Art Manifest

All art was generated to a consistent dark-fantasy style: blood-red/bone-white/void-black palette,
gold accents, eclipse motif, shattering-glass/crystal texture representing decaying god-memories.

Note: some cards are visual variants/near-duplicates of another card (18-20 echo 3/12/14/19-echo).
Kept as separate cards intentionally — can be used as "corrupted" alternate art for the same card,
or as two distinct cards if the content design calls for it. Flag this to Claude Code either way.
